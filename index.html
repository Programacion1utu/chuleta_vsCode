Crear y ejecutar un proyecto Java en VS Code

Pasos para crear un proyecto, ejecutarlo con un clic y moverse por las carpetas desde la terminal.

1 · Crear el proyecto
01

Abrir la paleta de comandos

Presionar Ctrl + Shift + P, escribir Java: Create Java Project y presionar Enter.

02

Elegir el tipo de proyecto

Seleccionar No build tools (proyecto simple, sin Maven ni Gradle).

03

Elegir dónde guardarlo

Seleccionar la carpeta de trabajo (por ejemplo Documentos\vs_workspace). El proyecto se crea dentro de esa carpeta.

04

Escribir el nombre del proyecto

Usar un nombre sin espacios ni tildes, por ejemplo PrimerEjemplo. VS Code abre el proyecto en una ventana nueva.

05

Reconocer la estructura

El código va siempre dentro de src:

PrimerEjemplo/
├── src/          ← acá van los archivos .java
│   └── App.java
├── bin/          ← .class compilados (no tocar)
└── lib/          ← librerías externas

Para agregar una clase nueva: clic derecho sobre src → New File → escribir el nombre con extensión, por ejemplo Main.java.

⚠ IMPORTANTE

El nombre del archivo debe coincidir exactamente con el de la clase, respetando mayúsculas: public class Main → Main.java.

2 · Ejecutar el programa
FORMA RÁPIDA

Desde el editor

Con el archivo abierto, usar cualquiera de estas opciones:

  • Clic en Run, que aparece justo encima de public static void main.
  • Clic en el botón ▶ arriba a la derecha.
  • Ctrl + F5 para ejecutar · F5 para ejecutar con depuración.

La salida aparece en la terminal de abajo. Si el programa usa Scanner, los datos se escriben ahí mismo.

DESDE LA TERMINAL

Compilar y ejecutar a mano

Primero ubicarse en la carpeta donde está el .java (ver sección 3).

# Opción A: compilar y después ejecutar
javac Main.java     # genera Main.class
java Main           # SIN la extensión .java

# Opción B: todo en un paso (Java 11 o superior)
java Main.java
3 · Moverse por carpetas en la terminal

Abrir la terminal con Ctrl + ñ o desde el menú Ver → Terminal. La línea PS C:\...> indica en qué carpeta se está trabajando.

ComandoQué hace
dirLista los archivos y carpetas de la carpeta actual.
cd srcEntra a la carpeta src.
cd ..Sube un nivel (vuelve a la carpeta anterior).
cd \Va a la raíz del disco (C:\).
cd "Mis proyectos"Entra a una carpeta con espacios: el nombre va entre comillas.
pwdMuestra la ruta completa de la carpeta actual.
clsLimpia la pantalla de la terminal.
TabAutocompleta nombres de archivos y carpetas. Escribir las primeras letras y presionar Tab.
↑ ↓Recorre los comandos escritos antes, para no volver a tipearlos.
Ctrl + CDetiene un programa que quedó corriendo (por ejemplo, un bucle infinito).

Ejemplo completo

PS C:\Users\alumno\Documents\vs_workspace\PrimerEjemplo> dir
    bin   lib   src          ← Main.java no está acá
PS ...\PrimerEjemplo> cd src
PS ...\PrimerEjemplo\src> javac Main.java
PS ...\PrimerEjemplo\src> java Main
Hola mundo
4 · Si algo falla
⚠ ERROR FRECUENTE

no se ha encontrado o cargado la clase principal Main.java

El archivo no está en la carpeta actual. Ejecutar dir para comprobarlo; si aparece la carpeta src, entrar con cd src y volver a ejecutar. Otra opción, sin cambiar de carpeta: java src\Main.java.

⚠ ERROR FRECUENTE

no se ha encontrado o cargado la clase principal Main (sin .java)

Falta compilar, o se está en otra carpeta. Ejecutar javac Main.java en la misma carpeta del archivo y después java Main.

⚠ ERROR FRECUENTE

class Main is public, should be declared in a file named Main.java

El nombre del archivo no coincide con el de la clase. Renombrar el archivo o la clase para que sean idénticos (mayúsculas incluidas).

⚠ NO APARECE EL BOTÓN RUN

VS Code no detecta Java

Verificar que esté instalada la extensión Extension Pack for Java. Luego Ctrl + Shift + P → Java: Configure Java Runtime y comprobar que haya un JDK detectado. Desde la terminal también se puede revisar:

java -version     # versión que se está usando
where java        # todas las instalaciones; se usa la primera
